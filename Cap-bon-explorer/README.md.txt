# Cap Bon Explorer

## Présentation

Cap Bon Explorer est un site web qui présente la région du Cap Bon en Tunisie. Il permet de découvrir quelques activités et endroits touristiques de la région.

## Les pages du site

- **Accueil :** Une petite présentation du site.
- **Activités :** Pour voir les différentes activités, avec une recherche et des filtres.
- **Agenda :** Pour découvrir les événements.
- **Réservation :** Pour faire une réservation et calculer le prix.
- **Contact :** Pour trouver les informations de contact et envoyer un message.

## Technologies utilisées

- HTML
- CSS
- Bootstrap
- JavaScript

## Dossiers du projet

- CSS : le style du site.
- JS : les fichiers JavaScript.
- Images : les images utilisées dans le site.
- Docs : les documents du projet.
